## Start a node

1. [Docker Desktop](https://www.docker.com/products/docker-desktop/)
2. Terminal:

```bash
HOA_MESO_NAME="Sunset Oaks" curl -fsSL https://raw.githubusercontent.com/00ranman/extropy-engine/main/scripts/join-hoa-meso.sh | bash
```
